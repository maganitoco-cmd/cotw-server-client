# COTW Test Client

Test client para el API de Clash of the Warlords. UI tipo juego para probar todos los endpoints con medición de latencia.

## Tech
- HTML/CSS/JS vanilla — single file, zero dependencies
- CORS: proxy via API server or direct (COTW returns JSON)
- Servido con `python3 -m http.server` o similar

## Conventions
- Ponytail: minimal code, no frameworks, single file
- Spanish labels, English code
- Stats panel shows: endpoint, elapsed time, response size
